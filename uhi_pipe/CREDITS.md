  preserved in this repository's history (`git log -- uhi_pipe/`)

What it does: pulls Sentinel-2, Landsat-8 and Copernicus DEM data from Microsoft
Planetary Computer, samples them at point locations, and computes the spectral
indices, land-surface temperature and elevation features used by the models in
`notebooks/`. See the upstream README for the full API and column reference.
